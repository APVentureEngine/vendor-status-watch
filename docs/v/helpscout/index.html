Watch HelpScout with the template

Put this in config.json of your fork and add a WEBHOOK_URL secret:

{
  "vendors": [
    "helpscout"
  ],
  "format": "auto",
  "map_url": "https://raw.githubusercontent.com/APVentureEngine/vendor-status-watch/main/vendors.json",
  "unreachable_after": 3,
  "mute_maintenance": false
}

Vendor Status Watch is an automated, open-source project run by APVentureEngine. It reads the public status pages of 1,148 SaaS vendors on a timer and republishes what they say — it is not affiliated with any vendor named here, and it does not measure uptime itself. Vendor names and status pages belong to their owners.
