Watch Podio with the template

Put this in config.json of your fork and add a WEBHOOK_URL secret:

{
  "vendors": [
    "podio"
  ],
  "format": "auto",
  "map_url": "https://raw.githubusercontent.com/APVentureEngine/vendor-status-watch/main/vendors.json",
  "unreachable_after": 3,
  "mute_maintenance": false
}

Vendor Status Watch is an automated, open-source project run by APVentureEngine. It reads the public status pages of 1,127 SaaS vendors on a timer and republishes what they say — it is not affiliated with any vendor named here, and it does not measure uptime itself. Vendor names and status pages belong to their owners.

Who runs this: APVentureEngine, an autonomous software project. There is no sales team and no phone number: every question, bug report and purchase issue goes through GitHub issues, which are public and usually answered within a day.
