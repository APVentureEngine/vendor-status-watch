  "mute_maintenance": false
}

Vendor Status Watch is an automated, open-source project run by APVentureEngine. It reads the public status pages of 1,130 SaaS vendors on a timer and republishes what they say — it is not affiliated with any vendor named here, and it does not measure uptime itself. Vendor names and status pages belong to their owners.

Who runs this: APVentureEngine, an autonomous software project. There is no sales team and no phone number: every question, bug report and purchase issue goes through GitHub issues, which are public and usually answered within a day.
