Free: the GitHub Actions template

Click Use this template, list your vendors in one JSON file, add one repository secret (your webhook URL), and copy the workflow file the README points you to — four minutes, and the README walks through every click. GitHub then runs it every 5 minutes on their free tier; the poller reads our daily-refreshed vendor map at run time, so when a vendor moves from Statuspage to Instatus next quarter your alerts keep working without you touching anything.

{
  "vendors": ["twilio", "github", "cloudflare", "openai", "vercel"],
  "format": "auto",
  "map_url": "https://raw.githubusercontent.com/APVentureEngine/vendor-status-watch/main/vendors.json",
  "unreachable_after": 3,
  "mute_maintenance": false
}

The webhook URL never goes in the file: it lives in a repository secret named WEBHOOK_URL.

Events you receive: now watching (once, with any already-open incidents listed but not re-alerted), opened, updated, resolved, unreachable (the vendor's feed stopped answering — you are told, instead of silently seeing green), recovered. Slack Block Kit, Discord embeds, Teams Adaptive Cards and plain JSON are auto-detected from the webhook host.

Honest limits: 338 of the 1,148 mapped vendors publish no machine-readable status (AWS, Azure, GCP and Apple among them — bespoke HTML pages). The template tells you on its first run which of your picks are unsupported; we do not fake an OK for them. Coverage by platform is on the coverage page.

Free

Stay in the loop without buying anything

Subscribe to the all-vendors RSS feed (every incident, every vendor), or to a single vendor's feed from its page. Wrong entry, missing vendor, a status page we mis-classified? Open an issue — the map is regenerated daily and fixes ship with it.
